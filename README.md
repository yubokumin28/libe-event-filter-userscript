# リベ イベント フィルター

リベシティのイベントカレンダーを、自分の地域・興味の言葉・カテゴリーで絞り込む、Tampermonkey 用のユーザースクリプトです。
チェックした予定は、日時・場所・リベシティのイベントのURLを書き込んだ Googleカレンダーの作成画面(下書き)で開けます。保存は利用者が押します。

- 使い方と入れ方: https://yubokumin28.github.io/libe-event-filter-userscript/
- インストール(Tampermonkey が必要): https://raw.githubusercontent.com/yubokumin28/libe-event-filter-userscript/main/libe-event-filter.user.js

条件と一覧はすべて利用者のブラウザの中(Tampermonkey の保存場所)だけに置き、外へ送るものはありません。Googleのログイン情報や許可も預かりません。
リベシティ公式のツールではありません。
